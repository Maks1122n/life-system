# Жизнь в порядке — версия для своего сервера

Личная система: день, цели, карта сфер, задачи, неделя. Работает на Node.js 18+, без внешних зависимостей. Телефон и компьютер синхронизируются, вход по паролю.

## Установка одной командой (на сервере)

```bash
curl -fsSL https://raw.githubusercontent.com/Maks1122n/life-system/main/install.sh | bash -s -- 'ПРИДУМАЙ_ПАРОЛЬ'
```

Скрипт скачает файлы, поставит сервис и в конце напишет адрес, например `http://186.246.71.174:8090`.

Личных данных в репозитории нет. Чтобы перенести цели и задачи из версии в Claude: там «Настроить» → «Скопировать данные», здесь «Настроить» → вставить → «Загрузить».

## Что делает скрипт и чего не делает

- Проверяет, что порт 8090 свободен. Если занят, останавливается и ничего не меняет.
- Ставит Node.js, только если его нет. Существующий не обновляет, чтобы не задеть VPN и другие сервисы.
- Кладёт файлы в `/opt/life`, пароль в `/opt/life/.env` (доступен только root).
- Включает автозапуск `life` с лимитом памяти 150 МБ. Сам сервис занимает около 40 МБ.
- VPN, его настройки и другие сервисы не трогает.

## Полезное

- Обновить сервис: снова скопировать новый архив и запустить ту же команду. Данные в `/opt/life/data` сохраняются.
- Логи: `journalctl -u life -f`
- Резервные копии: `/opt/life/data/backup-*.json`, хранятся 14 последних дней.
- Сменить пароль: запустить `install.sh` с новым паролем.
- Удалить: `systemctl disable --now life && rm -rf /opt/life /etc/systemd/system/life.service`

## Безопасность

По адресу из цифр соединение не шифруется (http). Для личного пользования терпимо, но в чужом Wi-Fi пароль можно перехватить. Когда будет домен или поддомен, сервис стоит перевести на HTTPS.
